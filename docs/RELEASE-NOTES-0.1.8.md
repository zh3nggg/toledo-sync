## Automatic update checks

The Windows GUI now offers optional Windows startup, a check-and-sync on launch, and scheduled checks every 30 minutes, hour, 6 hours, or day. Settings are stored locally. Automatic checks run only while the app is open and the Toledo session is authorized, and they use the existing incremental sync manifest to avoid duplicate downloads.
