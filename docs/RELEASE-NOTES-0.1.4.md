## Configurable course-material layout

Choose how every course folder is organized:

- **Directly in the course folder** — Toledo folders and files are placed in `G0S96A Groups and Symmetries/`.
- **Named materials subfolder** — they are placed in `G0S96A Groups and Symmetries/<your chosen name>/`.

The setting is shared by the Windows GUI and the Windows/macOS/Linux CLI. The subfolder name is user data and does not change when the interface language changes. Existing configurations preserve their previous folder name until you save a new choice.
