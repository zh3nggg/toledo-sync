## Course discovery is now independent of sync selection

The Windows GUI now discovers every course in the configured programme, even if a course is unchecked for synchronization. A later discovery run also keeps a previously confirmed course link when no new match is found.

Course cards now say **Discovered** or **Not discovered**. “Not discovered” only means that Toledo has not provided a reliable current-year link to the app; it does not claim that the course is closed.
